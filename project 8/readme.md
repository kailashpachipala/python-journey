# 📝 Python To-Do List

A simple command-line To-Do List application built using Python.

This project is designed for beginners who want to practice Python fundamentals such as functions, lists, dictionaries, loops, file handling, JSON, and user input.

## 🚀 Features

- ➕ Add new tasks
- 📋 View all tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🧹 Clear all completed tasks
- 💾 Automatically save tasks
- 🔄 Load tasks when the program starts
- 🛡️ Basic input validation
- 📦 No external Python packages required
